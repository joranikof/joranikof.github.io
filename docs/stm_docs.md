# stm_docs.md

## 参考サイト

- STM32CubeIDE — 無料の統合開発環境（ST公式）
  - https://www.st.com/en/development-tools/stm32cubeide.html#get-software
- STM32CubeMX — ピン設定・クロック設定のGUIツール
- RM（Reference Manual） — 使用するチップのリファレンスマニュアル（ST公式サイト）
- AN（Application Note） — 各ペリフェラルの実装例

- 「Mastering STM32」(Carmine Noviello著) — 定番の技術書、無料PDF版あり
- STMicroelectronics公式YouTube — CubeMXやHALの使い方
